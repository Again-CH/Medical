架构

核心能力

人工审核门 (HITL)

锁号/结算/转诊/120 等敏感动作默认不自动执行，需医生 interrupt→resume 一次批准，合规可审计。

适配器双后端

工具体系统一端口（Protocol），Memory / Postgres 可插拔；DATABASE_URL 一变量切换真实持久化。

多用户鉴权

PyJWT + pbkdf2 密码哈希 + RBAC；审核接口仅 doctor 角色可见，患者端不可越权。

可部署 / 运维

Dockerfile + docker-compose + setup_local.sh + Makefile，本地 brew Postgres 即可起服务。

红线引擎

急症/违规词库前置拦截，AI 不下诊断；命中强制转急诊人工。

评测门禁 (CI)

意图 / 红线 / 端到端三线评测，全部 hermetic、确定性，作为 CI 守门员。

本地运行

# 1. 起依赖（本地 brew Postgres 即可，无需 Docker）
brew services start postgresql@18
createdb medical_agent

# 2. 安装与初始化
python -m venv .venv && source .venv/bin/activate
pip install -e .
cp .env.example .env          # 默认 Ollama + 本地 PG；可填 Deepseek key 跑真实对话
make db-up && make seed

# 3. 起服务 + 浏览器演示
make run                      # http://localhost:8000
# 患者端 / 与 医护审核台 /review 同源托管，演示账号见 README

# 4. 跑评测门禁
make ci-local                 # lint + pytest + offline eval
